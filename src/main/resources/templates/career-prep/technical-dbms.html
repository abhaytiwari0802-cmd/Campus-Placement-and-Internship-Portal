Core DBMS Theoretical Concepts

  • Atomicity: "All-or-nothing" execution. If an application status changes to SELECTED, recording the history entry and generating student notification must both succeed or neither does.
  • Consistency: The database transitions from one valid state to another valid state, respecting all constraints (e.g., foreign keys, unique constraints on user email).
  • Isolation: Concurrent transactions execute without interfering with one another. Handled through locking and transaction isolation levels.
  • Durability: Once a transaction commits, the written data persists permanently even in the event of an abrupt system power loss (via write-ahead redo logs in MySQL InnoDB).

  1. 1NF (First Normal Form): Each column contains atomic (indivisible) values, and no repeating groups exist.
  2. 2NF (Second Normal Form): Must be in 1NF, and all non-key attributes are fully functionally dependent on the entire primary key (no partial dependencies on composite keys).
  3. 3NF (Third Normal Form): Must be in 2NF, and no non-key attribute is transitively dependent on the primary key (no X → Y → Z transitive dependency).
  4. Boyce-Codd Normal Form (BCNF): A stricter 3NF where for every functional dependency X → Y, X must be a super key.

An index is a balanced tree (B+ Tree) data structure maintained to locate records in O(log N) disk reads instead of doing a full table scan O(N).

  • Clustered Index: Dictates the physical order of data on disk. Leaf nodes contain the actual complete table row data. There can only be ONE clustered index per table (typically the Primary Key in MySQL InnoDB).
  • Non-Clustered (Secondary) Index: Stored separately from the data rows. Leaf nodes contain index keys and a pointer (in InnoDB, the primary key value) to locate the main clustered row.

Frequently Asked SQL Interview Queries

1. Find the 2nd Highest Salary from an Employee Table

Can be solved using subquery with MAX() or modern SQL window functions DENSE_RANK():

-- Approach 1: Using Subquery & MAX
SELECT MAX(salary) AS second_highest_salary
FROM employees
WHERE salary < (SELECT MAX(salary) FROM employees);

-- Approach 2: Using DENSE_RANK() Window Function (Universal for Nth)
WITH RankedSalaries AS (
    SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS rank_pos
    FROM employees
)
SELECT salary FROM RankedSalaries WHERE rank_pos = 2;
2. Identify Duplicate Records in a Table
SELECT email, COUNT(*)
FROM users
GROUP BY email
HAVING COUNT(*) > 1;
3. Find Department-Wise Highest Earning Candidate / Placement Offer
SELECT department, full_name, ctc
FROM (
    SELECT department, full_name, ctc,
           ROW_NUMBER() OVER (PARTITION BY department ORDER BY ctc DESC) as rn
    FROM student_placements
) ranked
WHERE rn = 1;

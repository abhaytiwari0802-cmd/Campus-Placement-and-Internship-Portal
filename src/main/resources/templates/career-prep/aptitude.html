Key Quantitative Formulas & Shortcuts

1. Time & Work
  • If A can do a piece of work in n days, A's 1 day's work = 1/n.
  • If A is twice as good a workman as B, then ratio of work done = 2 : 1 and ratio of times taken = 1 : 2.
  • Combined work formula: Total Days = (A × B) / (A + B).
  • Pipes & Cisterns: Inlet fills at 1/x, outlet empties at 1/y. Net rate = 1/x - 1/y.
2. Speed, Distance & Time
  • Speed = Distance / Time; 1 km/h = 5/18 m/s; 1 m/s = 18/5 km/h.
  • Average speed for equal distances: (2 × u × v) / (u + v).
  • Relative speed in opposite directions: u + v; in same direction: |u - v|.
  • Trains passing a stationary object of negligible width: Distance = Length of train.
3. Profit, Loss & Percentage
  • Gain % = (Gain × 100) / Cost Price.
  • Loss % = (Loss × 100) / Cost Price.
  • Selling Price with Gain: SP = [(100 + Gain%) / 100] × CP.
  • Successive Percentage Change: a + b + (ab / 100)%.
4. Permutations, Combinations & Probability
  • Permutations (Arrangement): nPr = n! / (n - r)!.
  • Combinations (Selection): nCr = n! / [r! × (n - r)!].
  • Probability P(E) = n(E) / n(S), where 0 ≤ P(E) ≤ 1.
  • For mutually exclusive events: P(A ∪ B) = P(A) + P(B).

Campus Online Test Time Management Strategy
1. The 60-Second Rule: If an aptitude problem is not crackable within 60 seconds, flag it and move forward immediately.
2. Answer Elimination: Use option back-substitution (plugging values from options into equations) to solve algebra & age problems in half the time.
3. Accuracy over Guesswork: Most campus drive tests (TCS NQT, Infosys, Capgemini) penalize negative marks for wrong answers in advanced sections.

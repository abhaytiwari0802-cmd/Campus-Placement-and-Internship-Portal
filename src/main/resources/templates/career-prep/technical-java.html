Core Java Architecture & OOP Essentials

Stack Memory: Stores primitive local variables and execution frames for thread execution. Memory allocation is LIFO and automatically cleared when method execution finishes. Each thread has its own private stack.

Heap Memory: Shared among all threads; stores all instantiated objects. Divided into:

  • Young Generation: Eden space and Survivor spaces (S0, S1). Objects created here; collected by Minor GC.
  • Old (Tenured) Generation: Holds long-surviving objects. Major/Full GC runs here (e.g. G1GC, ZGC).
  • Metaspace (Java 8+): Replaced PermGen; allocated out of native OS memory for class metadata.

HashMap is an array of Node<K,V> buckets with a default capacity of 16 and a load factor of 0.75.

  1. When put(key, value) is invoked, it calculates hash(key) and maps to an index: index = (n - 1) & hash.
  2. If a collision occurs, entries are stored in a linked list.
  3. Java 8 Optimization: When the number of collisions in a single bucket exceeds the TREEIFY_THRESHOLD (8) and the total table capacity is at least 64, the bucket transforms from a linked list (O(n)) into a Red-Black Balanced Tree (O(log n)), preventing DoS collision attacks.

  • Records (Java 16+): Immutable data carriers that automatically generate private final fields, constructor, getters, equals(), hashCode(), and toString(): 
    public record UserDto(Long id, String email, String name) {}
  • Sealed Classes (Java 17+): Restrict which other classes or interfaces may extend or implement them: 
    public sealed class Shape permits Circle, Square {}
  • Virtual Threads (Project Loom, Java 21+): Lightweight threads managed by the JVM rather than the OS kernel. Millions of virtual threads can run concurrently with near-zero memory footprint, revolutionizing high-throughput I/O in Spring Boot 3.

The contract stipulates:

  • If two objects are equal via a.equals(b) == true, their hashCode() values MUST be equal.
  • If two objects have the same hashCode(), they do NOT necessarily have to be equal (hash collision).
  • If you override equals(), you MUST override hashCode(); otherwise, hashing collections like HashSet and HashMap will fail to locate or deduplicate objects correctly.

Spring Boot & Spring Framework Concepts

IoC: A software design principle where the control of object creation and lifecycle is inverted from application code to the framework container (ApplicationContext).

Dependency Injection: The mechanism by which the container injects required dependent objects into a bean.

Why Constructor Injection is Preferred:

  • Immutability: Dependencies can be declared as private final.
  • Null Safety: Prevents NullPointerException at runtime if a dependency is omitted.
  • Testability: Objects can easily be instantiated in unit tests using standard new Service(mockRepo) without needing Spring test reflection.
  • Prevents circular dependency traps at compile/startup time.

Spring uses AOP (Aspect-Oriented Programming) Proxies (CGLIB or JDK dynamic proxies). When a method annotated with @Transactional is called from outside the bean:

  1. The proxy intercepts the call and obtains a connection from the PlatformTransactionManager.
  2. It sets connection.setAutoCommit(false).
  3. The target business method executes.
  4. If the method completes normally, the proxy issues connection.commit().
  5. If an unchecked exception (RuntimeException or Error) is thrown, the proxy automatically invokes connection.rollback().

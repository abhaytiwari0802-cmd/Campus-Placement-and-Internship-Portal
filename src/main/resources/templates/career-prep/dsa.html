Top Algorithmic Interview Patterns

1. Two Pointers & Sliding Window

Used for linear sequences to reduce brute-force O(n²) nested loops to O(n) time complexity.

int left = 0, right = arr.length - 1;
while (left < right) {
    int sum = arr[left] + arr[right];
    if (sum == target) return new int[]{left, right};
    else if (sum < target) left++;
    else right--;
}
2. Breadth-First Search (BFS) vs DFS

BFS uses a Queue for level-order traversal and shortest path in unweighted graphs. DFS uses a Stack or recursion for connected components and topological sort.

Queue<Node> q = new LinkedList<>();
q.offer(root);
while (!q.isEmpty()) {
    Node curr = q.poll();
    if (curr.left != null) q.offer(curr.left);
    if (curr.right != null) q.offer(curr.right);
}
3. Dynamic Programming (DP) Core Principle

Breaking complex problems into overlapping subproblems with optimal substructure. Memoization (top-down) or Tabulation (bottom-up).

  • 0/1 Knapsack Problem
  • Longest Common Subsequence (LCS)
  • Coin Change Problem
  • Climbing Stairs / Fibonacci sequence
